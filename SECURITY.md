# Sécurité

Signaler une faille (fuite de secret, écriture non voulue vers un service tiers, contournement d'un garde-fou)
par un signalement privé de vulnérabilité sur GitHub : onglet Security du dépôt, « Report a vulnerability ».
Ne pas publier de détail dans une issue publique. Posture et flux de données :
[docs/PRIVACY_AND_SECURITY.md](docs/PRIVACY_AND_SECURITY.md).
